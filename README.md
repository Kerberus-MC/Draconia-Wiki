# Kerberus Wiki

Public wiki hub for Kerberus modpacks. Live at [wiki.kerberus.gg](https://wiki.kerberus.gg).

## Contributing

Click the pencil icon on any wiki page to edit it on GitHub, then submit a pull request. Pages are plain Markdown in `docs/`.

## Local Development

```bash
pip install -r requirements.txt
mkdocs serve
```

Site auto-deploys to GitHub Pages on push to `master`.
