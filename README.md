# Kerberus Wiki

Public wiki hub for Kerberus modpacks. Live at [wiki.kerberus.gg](https://wiki.kerberus.gg).

Built with [Astro Starlight](https://starlight.astro.build/). Pages are plain Markdown in `src/content/docs/`.

## Contributing

Click "Edit page" on any wiki page to edit it on GitHub, then submit a pull request.

## Local Development

```bash
npm install
npm run dev
```

Site auto-deploys to GitHub Pages on push to `master`.
